# Laboratorio de decisiones · NCompany

Prototipo web para un taller de toma de decisiones. Funciona en navegador y se adapta a móvil.

## Recorrido

1. Describe la situación, el objetivo y los límites.
2. Revisa tres caminos editables y escoge dos.
3. Compara pros, contras y datos pendientes.
4. Explica un orden provisional, toma tu decisión y define los próximos pasos.

La pestaña **Metodologías** permite buscar y aplicar una pregunta de reflexión entre 50 modelos. Las fichas son descripciones originales de uso basadas en *El pequeño libro de las grandes decisiones*; no reproducen sus explicaciones ni diagramas.

## Estado del prototipo

- La IA aún no está conectada. En los casos propios aparecen tres plantillas editables; el orden lo explica la persona.
- Los ejemplos de Luckia y de carrera son ficticios. El caso de Luckia es temporal y no representa una decisión de la empresa.
- El guardado voluntario usa el almacenamiento de este navegador. No hay cuentas ni acceso para facilitadores en esta versión.
- El informe se descarga como archivo Markdown.

## Probar en local

Sirve esta carpeta con un servidor HTTP estático, por ejemplo `python3 -m http.server 8000`, y abre `http://localhost:8000/`.
